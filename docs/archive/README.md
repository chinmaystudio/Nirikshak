# Archived development reports

These reports were written during development and describe earlier states of the system. Several claims in them, such as encrypted bid submission, test results and usability scores, were not re-verified for the handover. Do **not** treat them as authoritative. The current documents are:

- `HANDOVER.md`: state of the system and go-live steps
- `docs/OPERATIONS_RUNBOOK.md`: deployment and operations
- `docs/SECURITY_MODEL.md`: access rules and how they are tested

Credentials that appeared in these reports have been redacted. The corresponding accounts must be deleted from any live project (see the runbook).
